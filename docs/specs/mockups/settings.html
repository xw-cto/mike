Mike · Settings tab · groups, typed controls with units, JSON editor

Every setting lives in the config store, so there is no "From" column. Each row: label and key, one line of help, a control whose unit is part of the field, then who changed it, when, and the version. Secrets show their name and "set" or "not set", never the value. JSON settings open in an editor beside the list on desktop and full screen on the phone. A save names the version it is based on; a stale save is refused with the version that won (409). Dangerous changes confirm with the exact consequence. Running/Paused and live/dry-run sit at the top.
